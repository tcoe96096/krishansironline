KSOL Encrypted Backup

Owner-only data recovery utility for Krishan Sir Online Learning. This page describes the private Google Drive OAuth desktop app named KSOL-Encrypted-Backup.

Current status: Encrypted storage connectivity has been tested by the administrator; automatic production database backups and complete restore verification have not yet been activated or proven. This is not a student login application.

What it does

When separately enabled by the administrator, the utility will create, encrypt, upload, read back and verify backup files of the educational platform for recovery from data loss. It uses a private administrator-owned Google Drive folder via rclone crypt. Filenames and file contents are encrypted before transmission to Drive.

Google data access

The OAuth app requests the limited Google Drive drive.file scope for the backup files it creates or is explicitly authorized to use. The purpose is backup storage and retrieval, not reading unrelated Drive documents. The Google Account owner can revoke consent using Google Account connected-app settings; revocation can interrupt backups but does not automatically delete prior encrypted files.

Student information and security

If enabled, encrypted database backups may contain students' and teachers' information already stored by the educational platform, including accounts and examination results. Backup files are intended for authorized recovery use only. Crypt passwords and OAuth credentials are kept separate from publicly accessible website source code. No student is asked to authorize Google Drive access to use the learning portal.
